Supported Boards
================

The following boards are supported by this layer:
 * ROM-2820 (`imx93rom2820a1`)
 * AFE-E420 (`imx93afee420a1`)
 * ROM-2620 (`imx8ulprom2620a1`)
 * AOM-5521 (`imx95aom5521a2`)
 * RSB-3720 (`imx8mprsb3720a2`)
 * ROM-5722 (`imx8mprom5722a1`)
